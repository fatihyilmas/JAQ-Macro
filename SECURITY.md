# Security

This is a public documentation and release hub, not the proprietary source repository.

- Never post access tokens, API keys, passwords, license keys or private workflow backups in issues.
- Use the authenticated in-application Support area for reports that contain sensitive details. Do not attach secrets unless specifically required through a secure channel.
- Update descriptors use a pinned publisher key. A matching hash alone is not a substitute for a valid publisher signature.
- The current preview archive contains Markdown only. Treat any third-party “JAQ Macro executable” as unverified unless provided through an official application release.
- No universal game compatibility, protection bypass or performance guarantee is made.
